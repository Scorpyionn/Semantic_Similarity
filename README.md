## Experiment 8: Semantic Similarity Analysis

### Aim
To develop a semantic similarity analysis tool using WordNet and pre-trained word embeddings to measure semantic relationships between words and documents.

### Example Domain
Marine Conservation and Ocean Research.

### Methods Implemented
- WordNet Path Similarity
- Wu-Palmer Similarity
- Leacock-Chodorow Similarity
- Word2Vec using Gensim
- Pre-trained GloVe 50-dimensional embeddings
- TF-IDF document similarity
- Cosine similarity
- PCA dimensionality reduction

### Visualizations
- WordNet similarity bar chart
- Word2Vec and GloVe similarity heatmap
- TF-IDF document similarity heatmap
- Word2Vec document similarity heatmap
- PCA projection of word embeddings
